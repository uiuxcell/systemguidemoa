## Primary Color

### Primary Color는 브랜드의 핵심\n아이덴티티를 표현하거나 주요 액션을\n강조해요.

- Black & White: 디자인 시스템의 기본 컬러입니다.
- Skyblue 계열: 활성화 상태를 나타내며, 확인·성공 등 긍정적인 상태와 메시지를 전달하는 데 사용합니다.
| Black | #000000 |
| White | #FFFFFF |
| Skyblue | #2189FF |
| Skyblue Dark | #006BEA |
| Skyblue Light | #68AEFF |

추가 질문: 투명도 적용 규칙, 컬러 확장 규칙

## Secondary Color

### Secondary Color는 보조 강조나 정보성\n요소를 표현해야 하는 경우에 사용해요.

- Coral 계열: 경고·오류 등 부정적인 상태를 표현하는 용도로 사용합니다.
- Orange 계열: Skyblue와 조합하여 브랜드 아이덴티티를 표현할 때 보조적으로 사용합니다.
- Teal 계열: 할인율(%)이나 추천 등 정보성 태그의 텍스트 컬러로 사용할 수 있습니다.
| Coral | #EF3434 |
| Coral Dark | #D62E2E |
| Coral Light | #F36E6E |
| Orange | #F66700 |
| Orange Dark | #C74700 |
| Sea Blue | #00B3E3 |
| Teal | #00838F |
| Teal Dark | #007D89 |

추가 질문: 투명도 적용 규칙, 컬러 확장 규칙

## Grayscale

### Grayscale은 텍스트·배경·구분선 등의 시각적 위계를 설정해야 하는 경우 사용해요.
텍스트·배경·구분선의 시각적 위계는 정의된 Grayscale 10단계를 기준으로 관리합니다.

| 0_F7 | #F7F7F7 |
| 1_EE | #EEEEEE |
| 2_DD | #DDDDDD |
| 3_BB | #BBBBBB |
| 4_AA | #AAAAAA |
| 5_8F | #8F8F8F |
| 6_75 | #757575 |
| 7_55 | #555555 |
| 8_31 | #313131 |
| 9_1C | #1C1C1C |

추가 질문: 투명도 적용 규칙, 컬러 확장 규칙

## Neutral Color

### Neutral Color는 배경이나 카드 표면에\n은은한 컬러를 적용해야 하는 경우 사용해요.
텍스트 컬러로는 사용을 권장하지 않습니다.

| Neutral Blue | #F5F7FE |
| Neutral Beige | #F7F5F2 |
| Neutral Orange | #FEF6F3 |
| Neutral Pink | #F6F0F5 |

추가 질문: 투명도 적용 규칙, 컬러 확장 규칙

## Theme

### Theme는 배경의 밝기에 따라 텍스트 컬러의 명도 대비를 조정해야 해요.
KR은 전체 다크모드 대신 어두운 특정 영역을 기준으로 적용합니다.

라이트 배경에는 Dark 계열, 다크 배경에는 Light 계열을 사용하며, 텍스트와 배경의 명도 대비는 최소 4.5:1 이상을 유지합니다.

※ 배경과 충분한 대비가 없는 텍스트 색상은 사용하지 마세요

추가 질문: 투명도 적용 규칙, 컬러 확장 규칙
