## Action Chip

### Action Chip은 항목 선택 시 관련 동작을 실행하거나 해당 항목과 연관된 콘텐츠를 표시할 때 사용해요.
간결한 속성이나 항목을 표시하며, 사용자가 항목을 선택하여 콘텐츠를 필터링하거나 특정 동작을 실행할 때 사용해요.

칩 레이블은 명확하고 쉽게 알아볼 수 있도록 간결하고 일관된 스타일로 작성해요.

※ 칩 레이블은 가독성을 위해 최대 22자로 제한하고, 한 줄로 표시합니다.

![](img_chip_actionchip_01)

추가 질문: 스펙 및 토큰

## Select Chip

### Select Chip은 여러 항목을 선택하거나 선택 해제하고, 선택 결과에 따라 콘텐츠나 조건을 변경할 때 사용해요.
Select Chip은 선택 항목을 삭제할 수 있도록 오른쪽에 삭제 아이콘을 배치해요.

칩 레이블은 명확하고 쉽게 알아볼 수 있도록 간결하고 일관된 스타일로 작성해요.

※ 칩 레이블은 가독성을 위해 최대 22자로 제한하고, 한 줄로 표시합니다.

![](img_chip_selectchip_01)

추가 질문: 스펙 및 토큰, Option Chip, Selection Control
