## Drop down Menu

### Dropdown Menu는 여러 선택지 중 하나를 선택할 수 있도록 옵션 목록을 표시하는 메뉴예요.
콘텐츠의 카테고리나 항목을 선택할 때 사용해요.

Select Field 등 정의된 요소의 사용자 인터랙션을 통해 메뉴가 열리도록 구성하고, 독립적으로 사용하지 않아요.

메뉴의 Item(리스트)은 현재 선택된 항목을 명확하게 확인할 수 있도록 선택 상태를 구분해 표시해요. 

![](img_menu_all_01)

추가 질문: 스펙 및 토큰, Filter, List, Chip

## Icon Leading Menu

### Icon Leading Menu는 아이콘이나 버튼을 선택했을 때 관련 옵션 목록을 표시하는 메뉴예요.
특정 요소와 관련된 기능이나 추가 옵션을 제공할 때 사용해요.

아이콘이나 버튼을 통해 메뉴를 호출하고, 사용자 인터랙션에 따라 옵션 목록을 일시적으로 표시해요.

![](img_menu_all_02)

추가 질문: 스펙 및 토큰, Filter, List, Chip

## Select Field

### Select Field는 여러 선택지 중 하나를 선택하여 정보를 지정하거나 변경하는 컴포넌트예요.
콘텐츠의 정렬 기준을 선택하거나 특정 정보를 설정할 때 사용해요.

현재 선택된 값을 기본으로 표시하여 설정 상태를 확인할 수 있도록 하며, Select Field를 선택하면 연결된 Dropdown Menu가 표시되어 옵션을 선택할 수 있어요.

![](img_menu_all_03)

추가 질문: 스펙 및 토큰, Option Selector, Filter, Tab
