## Primary Action Button

### Primary Action Button은 주요 액션에\n사용해요.
페이지의 핵심 액션이나, 강하게 강조해야 하는 액션에 사용해요. 사용 용도에 따라서 Filled, Emphasis 이렇게 두가지 타입이 있어요.

### Filled (Primary)는 우선순위가 높은\n주요 액션에 적용해요.
페이지의 핵심 액션이나, 주요 액션에 사용해요.
(예: Buy now, Add to cart)

| Default | 40px |
| Small | 32px |

![](img_CTA Button_Primary_01)

### Filled (Emphasis)는 즉각적인 주목이\n필요한 최우선 액션에 사용해요.
즉각적인 주목이 필요한 최우선 액션에만 사용하며,
페이지당 1개, 오른쪽 상단 배치를 권장해요.

| Default | 40px |
| Small | 32px |

※ 리뷰 보기처럼 보조 액션에는 쓰지 않아요.

![](img_CTA Button_Primary_02)

추가 질문: 스펙 및 토큰, CTA Button Icon

## Secondary Action Button

### Secondary Action Button은 보조 액션에\n사용해요.
핵심 액션을 보조하는 중간 강조의 액션에 써요.
Outlined / Standard이 있어요.

### Outlined (Standard)는 중간 수준의 강조에 사용하는 테두리 버튼이에요.
Primary 버튼 오른쪽에 함께 배치하며, 추가 정보,
더보기 등에 사용해요. 앞이나 뒤에 아이콘을 붙일 수 있어요. (예: ∨ 펼치기, ↗ 새 창)

| Default | 40px |
| Small | 32px |

![](img_CTA Button_Secondary_01)

추가 질문: 스펙 및 토큰, CTA Button Icon

## Tertiary Action Button

### Tertiary Action Button은 강조 없이 가볍게 제공할 때 사용해요.
Primary, Secondary보다 가볍게 제공하는 선택적
액션에 써요.

### Underlined (Standard)는 강조를 최소화한 3순위 액션에 사용해요.
강조를 최소화한 텍스트 액션이며, 밑줄이 가운데에서 양옆으로 늘어나요. 모바일은 Pressed상태에 밑줄이 노출되요.

| Large | 16px |
| Default | 14px |
| Small (MO only) | 12px |

![](img_CTA Button_Tertiary_01)

### Label (Standard)는 시각적 강조 없이\n3순위 액션에 사용하는 텍스트에 적용해요.
강조 없이 덧붙이는 보조 액션이며,
앞이나 뒤에 16px 아이콘을 붙일 수 있어요.

| Default | 14px |

![](img_CTA Button_Tertiary_02)

추가 질문: 스펙 및 토큰, CTA Button Icon
