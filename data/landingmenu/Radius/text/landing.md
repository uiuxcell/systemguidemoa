# 타이틀
Radius의 구성이에요.
어떤게 궁금하신가요?

## 한 눈에 보기

### 4 px
작은 UI 요소의 컨테이너에 사용
적용: Option Chip, Option Selector, Check Box

![](img_radius_all_01)

### 6 px
버튼, 툴팁 등 중간 크기 컴포넌트의 컨테이너에 사용
적용: Snackbar, Text Field, Tooltip

![](img_radius_all_02)

### 8 px
큰 컴포넌트 또는 그룹화된 버튼에 사용
적용: Menu - Dropdown, Option Selector

![](img_radius_all_03)

### 20 px
카드, 배너, 이미지 등 중간 크기 컨테이너에 사용
적용: Card, Banner, Image

![](img_radius_all_04)

### 24 px
여러 UI 요소로 구성된 팝업 등 복합 컴포넌트에 사용
적용: Popup - PC

![](img_radius_all_05)

### Max : 999xp
버튼(CTA)과 같이 알약 형태의 높이가 고정된 요소에 사용
적용: Button (CTA), Indicator, Number Counter, Scroll, Search Field

| ’N’px (50%) | 높이 값의 50% 수치로 적용 가능 |

![](img_radius_all_06)

### None : 0px
리스트 또는 전체 화면 팝업 등 화면 너비를 가득 채우는 컨테이너에 사용
적용: List, Popup - Full Screen

![](img_radius_all_07)

## 4px

### 4px은 작은 UI 요소의 컨테이너에 사용해요.
뱃지, 옵션 칩, 체크박스, 옵션 셀렉터 등의 작은 엘리먼트 코너에 적용해요.

![](img_radius_all_01)

추가 질문: 스펙 및 토큰, Option Chip, Filter, Tab

## 6px

### 6px은 버튼, 툴팁 등 중간 크기 컴포넌트의 컨테이너에 사용해요.
스낵바(토스트 알림), 텍스트 필드, 툴팁 등의 코너에 적용해요.

![](img_radius_all_02)

추가 질문: 스펙 및 토큰, Snackbar, Text Field, Tooltip

## 8px

### 8px은 큰 컴포넌트 또는 그룹화된 버튼에 사용해요.
드롭다운 메뉴, 옵센 셀렉터 등의 코너에 적용해요.

![](img_radius_all_03)

추가 질문: 스펙 및 토큰, Menu, Option Selector

## 20px

### 20px은 중간 크기 컨테이너에 사용해요.
카드, 배너, 이미지 등의 코너에 적용해요.

![](img_radius_all_04)

추가 질문: 스펙 및 토큰

## 24px

### 24px은 여러 UI 요소로 구성된 팝업 등 복합 컴포넌트에 사용해요.
팝업, 또는 대형 컨테이너의 코너에 적용해요.

추가 질문: 스펙 및 토큰, Popup

## Max

### Max : 999xp은 높이가 고정된 요소에 사용해요.
버튼(CTA), 인디케이터, 스크롤 등 알약(Pill) 형태 컴포넌트의 코너에 적용해요.

컴포넌트 높이 값의 50% 수치로 적용 가능해요.

![](img_radius_all_06)

추가 질문: Button (CTA), Indicator, Scroll

## None

### None : 0px은 화면 너비를 가득 채우는 컨테이너에 사용해요.
리스트 또는 전체 화면 팝업 등의 코너에 적용해요.

![](img_radius_all_07)

추가 질문: List, Popup
