# FAQ (답변 형식 예시)

`DB_FAQ.csv` — 노션 DB_FAQ에서 내려받은 CSV. 카테고리별 **예상 질문 → 봇 응답 예시**.

- 챗봇은 질문과 비슷한 예시(현재 카테고리 우선, 최대 3개)를 골라 **문장 구조·어투·목록 형식**을 그대로 따릅니다.
- `{component}`, `{value}`, `{token}` 같은 변수 자리는 `DB_guide` / `DB_tokens`에서 찾은 실제 값으로 채웁니다. 근거가 없으면 생략합니다.
- 필요한 열: `카테고리 (연결 DB)`, `[questions] 예상 질문`, `봇 응답 예시` (열 순서 무관, `변수 구성`은 선택).
- 카테고리 값의 번호·괄호(`01_Color (색상) (https://…)`)는 자동 제거되어 `Color`처럼 DB_guide 주제와 맞춰집니다.
- 파일을 같은 이름으로 덮어쓰면 실행 중 다시 읽습니다 (미리보기: 저장, 플러그인: GitHub push). `node build.js`로 내장본도 갱신됩니다.
