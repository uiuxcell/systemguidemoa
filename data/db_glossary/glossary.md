### 0.1. Color (컬러)

- `color` : 컬러, 색, 색상 값
- `commonColor`: 공통 컬러, 공통 색상, 기본 컬러, 공통 색상 규칙, 시스템 컬러

- `neutralColor`: 뉴트럴 컬러, 중성색, 배경/테두리 색상, 무채색 계열, 기본 텍스트 색상
- `theme`: 테메, 테마, 테마 컬러, 스킨, 라이트/다크 모드, 브랜딩 테마

- `typeface` : 타입페이스, 타이포, 폰트, 글꼴, 서체, 폰트패밀리

- `body`: 바디, 본문 서체, 본문 텍스트, 기본 글씨 크기, 일반 텍스트
- `samsungOneKorean`: 삼성원고딕, 삼성원 코리안, SamsungOne 폰트, 기본 고딕 서체

### 0.3. Spacing (간격)

- `spacing` : 스페이싱, 여백, 간격
- `commonSpacing`: 공통 간격, 기본 여백, 스페이싱 가이드, 여백 규칙

- `pageLevel`: 페이지 레벨, 화면 여백, 외곽 마진, 전체 페이지 마진, 최상위 간격
