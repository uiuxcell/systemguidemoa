## 1. 개요

### 1.1. 정의

- **정의:** 뱃지는 텍스트, 숫자, 점(Dot), 아이콘 등을 활용하여 콘텐츠의 상태, 수량 및 부가 정보를 간결하고 직관적으로 전달하는 컴포넌트입니다.
- **사용 목적:** 제품 및 콘텐츠와 관련된 주요 정보, 신규 업데이트, 혜택 및 알림 등을 시각적으로 강조하여 사용자가 필요한 정보를 빠르게 인지하도록 돕습니다.
- **기본 원칙:** 정보의 성격과 사용 목적에 적합한 타입을 선택하고, 정의된 사용 규칙과 디자인 가이드라인을 준수하여 일관되게 적용합니다.

### 1.2. 적용 상황

- `filled` : 혜택, 프로모션, 추천 기획전 등 핵심 세일즈 정보를 강조할 때 사용합니다.
- `label` : 프로덕트 카드 내부나 텍스트 리스트 등 정보가 밀집된 영역에서 간결한 텍스트 강조가 필요할 때 사용합니다.
- `dot` : 제한된 공간에서 업데이트나 신규 정보의 존재 여부만 간단하게 전달할 때 사용합니다.
- `number` : 장바구니, 알림 목록 등 확인이 필요한 항목의 구체적인 수량을 표시할 때 사용합니다.
- `icon` : 오늘보장, 빠른배송 등 물류·배송 서비스의 특화된 정보를 정형화된 브랜드 에셋으로 전달할 때 사용합니다.

## 2. 사용 규칙 (Usage Rules)

### 2.1. 공통 규칙

- status: `MUST`
    
    content: 콘텐츠의 성격과 전달 목적에 맞는 적절한 뱃지 타입을 선택하여 사용한다.
    
- status: `MUST`
    
    content: 하나의 영역에는 원칙적으로 하나의 뱃지만 사용하여 정보의 중복 강조 및 시각적 혼잡을 방지한다.
    
- status: `MUST`
    
    content: 각 타입에 정의된 형태, 컬러 및 디자인 가이드라인을 준수하여 일관되게 적용한다.
    
- status: `MUST`
    
    content: 텍스트 또는 아이콘과 뱃지를 결합할 경우, 원본 콘텐츠의 가독성과 레이아웃을 침범하지 않도록 정의된 상대 위치 및 마진 규칙을 준수한다.
    
- status: `AVOID`
    
    content: 피그마 컴포넌트의 기본 속성을 임의로 해제(`Detach`)하거나 형태, 크기, 패딩, 라운드 및 폰트 규격을 변경하여 사용하는 것을 금지한다.
    
- status: `AVOID`
    
    content: 지정된 컨테이너 및 텍스트 컬러를 임의의 색상으로 변경하거나 정의되지 않은 스타일을 적용하는 것을 금지한다.
    
- status: `AVOID`
    
    content: 뱃지를 이미지로 대체하거나 가이드라인에 정의되지 않은 형태로 변형하여 사용하는 것을 금지한다.
    

### 2.2. 타입 선택 기준

- filled:
    - status: `SHOULD`
        
        content: 배경색과 텍스트를 함께 강조해야 하는 핵심 세일즈 정보(예: 추천 기획전, 구매 혜택, 프로모션 등)를 표시할 때 사용한다.
        
- label:
    - status: `MUST`
        
        content: 프로덕트 카드나 텍스트 리스트 등 정보가 밀집되어 배경색이 채워진 뱃지가 시각적 노이즈를 유발할 수 있는 영역에서 사용한다.
        
- dot:
    - status: `MUST`
        
        content: 구체적인 텍스트나 숫자 없이 신규 정보 및 알림의 존재 여부만 최소한의 형태로 전달할 때 사용한다.
        
- number:
    - status: `MUST`
        
        content: 장바구니나 알림 등 확인해야 할 항목의 구체적인 수량을 전달할 때 사용한다.
        
- icon:
    - status: `MUST`
        
        content: 오늘보장, 빠른배송 등 물류·배송 관련 정보를 정형화된 브랜드 에셋으로 표현할 때 사용한다.
        

### 2.3. 타입별 사용 규칙

#### 2.3.1. Type: filled

- status: `MUST`
    
    content: 제품 및 관련 정보에서 시각적 강조가 필요한 핵심 혜택이나 프로모션 정보에 사용한다.
    
- status: `AVOID`
    
    content: 프로덕트 카드 내부에서는 사용하지 않으며, 해당 영역에는 `type = label`을 적용한다.
    
- status: `AVOID`
    
    content: 정의되지 않은 배경색, 텍스트 컬러 및 형태를 임의로 적용하지 않는다.
    

#### 2.3.2. Type: label

- status: `MUST`
    
    content: 별도의 배경색이나 테두리 없이 텍스트만 노출하는 형태를 유지한다.
    
- status: `MUST`
    
    content: 프로덕트 카드 내부에서 뱃지가 필요한 경우 해당 타입을 사용한다.
    
- status: `MUST`
    
    content: 사용자가 직접 입력하는 라벨은 가독성을 위해 최대 18자로 제한한다.
    
- status: `AVOID`
    
    content: 임의의 배경색, 테두리 또는 장식 요소를 추가하지 않는다.
    

#### 2.3.3. Type: dot

- status: `MUST`
    
    content: 신규 업데이트나 알림의 존재 여부를 나타내는 용도로만 사용한다.
    
- status: `MUST`
    
    content: 텍스트 및 숫자 없이 단일 점 형태를 유지한다.
    
- status: `MUST`
    
    content: 정의된 고정 크기와 형태를 유지하며 콘텐츠에 따라 크기가 가변적으로 변경되지 않도록 한다.
    
- status: `AVOID`
    
    content: 라벨, 테두리 또는 별도의 텍스트 요소를 추가하지 않는다.
    

#### 2.3.4. Type: number

- status: `MUST`
    
    content: 알림, 장바구니 등 관련 항목의 수량을 표시하는 용도로 사용한다.
    
- status: `MUST`
    
    content: 수량이 99 이하인 경우 실제 숫자를 표시하고, 99를 초과하는 경우 `99+`로 표시한다.
    
- status: `MUST`
    
    content: 숫자만 표시하며, `99+`를 제외한 특수 기호 및 한글·영문 텍스트의 단독 표기를 금지한다.
    
- status: `MUST`
    
    content: 일반 숫자와 `99+` 상태는 각각 정의된 고정 형태를 사용하며, 콘텐츠 길이에 따른 가변 확장을 허용하지 않는다.
    
- status: `MUST`
    
    content: GNB 아이콘과 결합할 경우 터치 영역이 아닌 실제 아이콘 그래픽 영역의 우상단을 기준으로 배치한다.
    
- status: `AVOID`
    
    content: 수량 변화에 따라 뱃지 크기를 임의로 늘리거나 형태가 찌그러지도록 변형하지 않는다.
    

#### 2.3.5. Type: icon

- status: `MUST`
    
    content: 오늘보장, 빠른배송 등 물류·배송 관련 서비스 정보를 전달하는 용도로 사용한다.
    
- status: `MUST`
    
    content: 사전에 정의된 독립 벡터 에셋을 사용하고, 원본 형태와 비율을 유지한다.
    
- status: `MUST`
    
    content: 정의된 브랜드 컬러 및 고정 크기를 유지한다.
    
- status: `AVOID`
    
    content: 텍스트 가독성이나 레이아웃 조정을 이유로 에셋을 임의로 축소하거나 변형하지 않는다.
