## Standard

### Standard는 누르면 한 번 실행되는 동작을 아이콘으로 제공할 때 사용해요.
장바구니·비교함에서 항목 삭제 (휴지통)

제품 페이지 공유, 메뉴얼·자료 다운로드

안내 문구 옆 정보(i) 아이콘으로 툴팁 열기

![](img_CTA Button Icon_Standard_01)

## Toggle

### Toggle 버튼 아이콘은 켜고 끄는 동작을 아이콘으로 제공할 때 사용해요.
제품 목록 카드의 이미지 모서리에 둔 위시리스트 및 제품 상세 페이지의 위시리스트 담기·빼기는 하트 아이콘을, 품절 제품의 재입고 알림 받기·끄기는 벨 아이콘을 사용해요.

실제 사용 크기는 Container 40x40, Icon 24x24로 구성됩니다.

![](img_CTA Button Icon_Toggle_01)

## Play

### Play 버튼 아이콘은 영상을 재생하거나\n멈출 때 사용해요.
메인 KV·제품 소개 영역의 영상 재생 Default 사이즈 사용, 제품 갤러리 썸네일·카드 안의 영상 Small 사이즈를 사용해요.

| Default | PC 96 x 96, MO 56 x 56 |
| Small | PC 36 x 36, MO 24 x 24 |

![](img_CTA Button Icon_Play_01)
